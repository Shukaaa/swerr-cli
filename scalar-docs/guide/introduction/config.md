# Configuration

## Structure

```typescript
interface SwerrConfig {
  schemaVersion?: 1;
  project?: {
    name?: string;
    version?: string;
    description?: string;
  };
  scan: {
    directories: string[];
    ignoredDirectories?: string[];
    includeExtensions?: string[];
    requireErrorTag?: boolean;
    maxFileSizeBytes?: number;
    errorBlockDetector?: (context: ErrorBlockDetectorContext) => boolean;
  };
  sourceOutput?: {
    enabled?: boolean;
    directory?: string;
    fileName?: string;
  };
  converters?: ConverterConfig<unknown>[];
}

interface ConverterConfig<CFG> {
  factory: ConverterFn<CFG>;
  config: CFG;
}

type ConverterFn<CFG> = (
  config: CFG,
  scheme: SwerrScheme
) => Promise<void> | void;

interface ErrorBlockDetectorContext {
  jsDocTags: JsdocTag[];
  fileName: string;
  fileContent: string;
  block: JsdocBlock;
}
```

## `schemaVersion`

The current configuration schema version is `1`. It makes future schema migrations explicit.

## `project`

Project metadata is added to the generated `SwerrScheme`.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `string` | `""` | Project or API name |
| `version` | `string` | `"1.0.0"` | Project or API version |
| `description` | `string` | `"Generated by Swerr"` | Project description |

## `scan`

The `scan` section controls source discovery and JSDoc extraction.

### `directories`

Type: `string[]` required

Directories are resolved relative to the directory containing the configuration file. Multiple directories are scanned sequentially and their results are combined before conversion.

```javascript
directories: ["./src/errors", "./packages/shared/src/errors"]
```

### `ignoredDirectories`

Type: `string[]`

Directory names that should be skipped while scanning. Swerr always skips common generated and dependency directories such as `node_modules`, `.git`, `dist`, `build`, and `coverage`. This option adds project-specific directory names.

### `includeExtensions`

Type: `string[]`

Only files with one of these extensions are read. Extensions may be written with or without a leading dot and are normalized to lowercase.

```javascript
includeExtensions: [".js", ".ts"]
```

An empty list means that all file extensions are eligible.

### `requireErrorTag`

Type: `boolean`, default: `false`

When `true`, only JSDoc blocks containing an `@error` tag are included in the generated scheme. When `false`, every scanned JSDoc block is eligible unless an `errorBlockDetector` is configured.

### `maxFileSizeBytes`

Type: `number`, default: `2097152`

Maximum file size in bytes. Files larger than this limit are skipped.

### `errorBlockDetector`

Type: `(context: ErrorBlockDetectorContext) => boolean`

Optional custom detector. It receives the JSDoc tags, file name, complete file content, and parsed block. Returning `true` includes the block in the scan result.

```javascript
errorBlockDetector: ({fileName, fileContent}) =>
  fileName.endsWith("Exception.js") && fileContent.includes("extends Error")
```

## `sourceOutput`

Controls whether the generated `SwerrScheme` is also written as a JSON file. Converters receive the scheme regardless of this setting.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | `boolean` | `false` | Write the generated scheme to disk |
| `directory` | `string` | `"./docs"` | Output directory |
| `fileName` | `string` | `"swerr-source.json"` | JSON file name |

Relative output directories are resolved relative to the configuration file.

## `converters`

Converters consume the generated scheme and create the final documentation formats. They run sequentially in the order in which they are registered.

```javascript
converters: [
  {
    factory: markdownConverter,
    config: {
      outputPath: "./docs",
      fileName: "errors.md",
    },
  },
]
```

Each entry contains:

- `factory`: converter function
- `config`: converter-specific configuration

For built-in converters, a relative `outputPath` is resolved relative to the configuration file.

## Complete example

```javascript
import {htmlConverter, markdownConverter} from "@swerr/converter";

export default {
  schemaVersion: 1,
  project: {
    name: "My API",
    description: "API error documentation",
    version: "1.0.0",
  },
  scan: {
    directories: ["./src/errors", "./packages/shared/src/errors"],
    ignoredDirectories: ["fixtures"],
    includeExtensions: [".js", ".ts"],
    requireErrorTag: false,
  },
  sourceOutput: {
    enabled: true,
    directory: "./docs",
    fileName: "swerr-source.json",
  },
  converters: [
    {
      factory: htmlConverter,
      config: {
        outputPath: "./docs",
        fileName: "errors.html",
      },
    },
    {
      factory: markdownConverter,
      config: {
        outputPath: "./docs",
        fileName: "errors.md",
      },
    },
  ],
};
```

Existing configuration files from earlier schema versions are normalized for compatibility. New configurations should use the schema above.
